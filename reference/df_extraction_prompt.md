# Build the extraction prompt for one study

Build the extraction prompt for one study

## Usage

``` r
df_extraction_prompt(identifier, metawoRld_path = ".", metadata = NULL)
```

## Arguments

- identifier:

  Study identifier.

- metawoRld_path:

  Project root.

- metadata:

  Optional known bibliographic metadata; by default taken from the
  metadata cache.

## Value

A single string.
